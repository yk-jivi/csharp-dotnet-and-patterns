## 1. Объектно-ориентированное программирование (3 семестр)

Папка: [`01-oop-3rd-semester/`](01-oop-3rd-semester/)

Базовый курс изучения языка C# и ключевых парадигм ООП:
- **Базовый синтаксис и классы:** Инкапсуляция, модификаторы доступа, конструкторы, деструкторы.
- **Наследование и полиморфизм:** Виртуальные методы (`virtual`, `override`), абстрактные классы, интерфейсы (`interfaces`).
- **Перегрузка операторов:** Пользовательские операторы для классов и структур.
- **Обобщения (Generics) и Коллекции:** `List<T>`, `Dictionary<TKey, TValue>`, `Queue<T>`, `Stack<T>`.
- **Делегаты, события и лямбда-выражения:** `Action`, `Func`, `Predicate`, создание пользовательских событий.
- **LINQ to Objects:** Фильтрация, проекции, сортировки, агрегации над коллекциями объектов.
- **Работа с потоками данных и сериализация:** JSON, XML, бинарная сериализация, файловый ввод-вывод.

## 2. Разработка десктопных приложений на WPF (4 семестр)

Папка: [`02-oop-4th-semester-wpf/`](02-oop-4th-semester-wpf/)

Центральная часть курса — пошаговое проектирование и разработка полноценного десктопного приложения **BookStore** на базе **WPF (Windows Presentation Foundation)** и языка разметки **XAML**:

- **Эволюция проекта BookStore (Лабы 4–11):**
  - **Верстка интерфейса (XAML):** Сетки `Grid`, панели `StackPanel`, `WrapPanel`, `DockPanel`.
  - **Элементы управления:** Текстовые поля, выпадающие списки, кастомные кнопки, `DataGrid`, `ListView`.
  - **Привязка данных (Data Binding):** Односторонняя и двусторонняя привязка (`OneWay`, `TwoWay`), контекст данных `DataContext`.
  - **Стили и шаблоны (Styles & ControlTemplates):** Создание кастомного визуального стиля приложения, триггеры событий.
  - **Валидация данных:** Реализация интерфейса `IDataErrorInfo`, визуальные подсказки ошибок ввода при добавлении книг.
  - **Пользовательские контролы (User Controls):** Вынесение переиспользуемых элементов карточки книги и навигации.
  - **Поиск, сортировка и фильтрация каталога:** Фильтрация по жанрам, авторам, ценовому диапазону.

## 3. Паттерны проектирования (GoF Design Patterns)

Папка: [`03-design-patterns/`](03-design-patterns/)

Практическая реализация классических шаблонов банды четырех (Gang of Four) на платформе .NET:

| Категория | Паттерны | Назначение |
| :--- | :--- | :--- |
| **Порождающие (Creational)** | Singleton, Factory Method, Abstract Factory, Builder, Prototype | Гибкое создание объектов без жесткой привязки к конкретным классам |
| **Структурные (Structural)** | Adapter, Decorator, Facade, Proxy, Composite | Организация удобной структуры классов и слабая связанность компонентов |
| **Поведенческие (Behavioral)** | Strategy, Observer, Command, Iterator, State | Эффективное взаимодействие и распределение обязанностей между объектами |

## 🚀 Как запустить проекты

1. Установите **Visual Studio 2022** (с установленной рабочей нагрузкой *«Разработка классических приложений .NET»*).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yk-jivi/csharp-dotnet-and-patterns.git
   ```
3. Откройте файл решения `.sln` нужного проекта и нажмите **F5** (Запуск с отладкой).
